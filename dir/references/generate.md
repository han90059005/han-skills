# 生成目录

目标：按用户描述，从零产出目录结构和文件。

## 流程

1. 确认目标：目标路径、用途、技术栈或语言、大致需要哪些文件。信息不足时只做最少的必要澄清，不逐条追问；其余按合理默认补全并说明。
2. 给文件清单：动手前用简短列表给出计划（每个文件一行，附一句用途），让用户一眼能改。大项目先给顶层结构。
3. 创建文件：逐文件写入，文本统一 UTF-8；按需补 `.gitignore` 和 `README.md`。
4. 自检：`python scripts/snapshot.py <目标目录> --markdown`，确认文件齐全、内容正确、没有多余文件。
5. 交付：给出目录树和一句话说明，并提示可以如何继续。

## 要点

- 若用户给了参考目录或模板，先用 snapshot 打包参考，再据此生成，不要凭空猜。
- 骨架文件一次写完再逐个补全，避免漏文件；生成过程保持目录结构清晰。
- 不要擅自覆盖目标目录里已有的同名文件，先提示。
