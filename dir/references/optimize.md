# 优化目录

目标：审查已有目录，给出并（确认后）实施改进。

## 流程

1. 打包：`python scripts/snapshot.py <目录> --markdown -o <快照>.md`，必要时加 `--include-hidden`。把快照读进来分析。
2. 分析：从快照中找：冗余或重复文件、命名与结构混乱、坏味道、缺失的 `.gitignore`/`README.md`、可合并或拆分的文件、明显的 bug。
3. 出方案：给改动清单（新增 / 修改 / 删除 / 移动，各带目标路径和原因），标出风险项。默认停下等用户确认。
4. 实施：确认后逐项修改；删除或移动前再次列出明确的绝对目标路径。
5. 验证：重新 snapshot，确认改动生效、没有遗漏；有测试就顺手跑一遍。

## 要点

- 快照是只读快照，改动要落到真实文件，不要只改快照。
- 大改动分批做，每批一次验证。
- 只优化用户指定的目录，不扩大范围、不动目录外的东西。
