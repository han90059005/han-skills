# leave-note

把「请假日期」变成一份可直接打印/上交的《家长知情同意书》：A4、四号宋体、标题小二加粗、右下角家长手写签名 + 联系电话 + 落款日期。产出 **PDF + 300 DPI JPG**，并同步到资料目录。

**不要手写 LaTeX，也不要从头搭环境**——模板、签名图、编译流程都在本技能里，跑脚本即可。

## 什么时候用

用户给出一段请假信息，例如：

- 「我 10 月 27 号到 10 月 29 号去上海落款 10 月 26 号」
- 「请假条：11.21–11.23 成都，落款 11.20」
- 只发一句「请假条」→ 先问缺的信息

## 必须先拿到的四项

| 项 | 说明 | 缺失时 |
| --- | --- | --- |
| 离开日期 | 正文「于 2026.10.27」 | **问**，不猜 |
| 返校时间 | 正文「返校时间为 2026.10.29」 | **问**，不猜 |
| 前往地点 | 正文「前往上海」 | **问**，不猜（「灞桥区」是历史默认值，别沿用） |
| 落款日期 | 右下角签署日期 | 没给就默认**今天**，并在回报里说明 |

日期写法随意（`2026-10-27` / `2026.10.27` / `2026年10月27日` / `10-27`），脚本自己归一。**只给「10 月 27 号」这种缺年份的，按当前年份补，并在回报里点明补的是哪一年。** 返校时间早于离开日期 → 先跟用户确认，别硬生成。

## 一条命令

```bash
python scripts/build_leave_note.py --leave 2026-10-27 --return 2026-10-29 --dest 上海 --sign 2026-10-26
```

- 默认输出到 `<当前目录>/leave-note/`，文件名固定 `家长知情同意书.tex / .pdf / .jpg`
- 默认把三个文件复制到 `I:\学习资料\0-个人资料\2-请假`（写工作区外，需要审批；审批没通过就加 `--no-copy`，先把工作区里的文件给用户）
- `--out DIR` 换输出目录，`--copy-dir DIR` 换复制目标，`--no-copy` 只生成不复制

Windows 上用真实解释器路径跑（`python` 可能是应用商店占位符）：

```
C:\Users\admin\AppData\Local\Programs\Python\Python312\python.exe
```

脚本自带：模板填充 → 拷签名图 → 编译 → 出 JPG → 复制 → 清理 `.aux/.log`。

## 签名图怎么插的（别自己改）

- 宽 **2.23cm**（高按原比例 1.00cm），取自原 docx `word/document.xml` 里的显示尺寸，放大到整张纸就失真
- 写法：`\begin{flushright} 签字：\includegraphics[width=2.23cm]{signature.jpg}\\[1.5em] ...`
- 图片文件名用 ASCII（`signature.jpg`），中文文件名有 XeLaTeX 路径兼容坑
- 优先用资料目录里的 `家长签名.jpg`（换签名后就自动生效），没有才回退技能自带的 `assets/signature.jpg`

## 版式（复刻原件，别动）

| 项 | 值 |
| --- | --- |
| 纸张/边距 | A4，上下 2.54cm，左右 3.17cm |
| 正文 | `\zihao{4}`（四号），首行缩进 2 字符（ctex 默认） |
| 标题 | 「家长知情同意书」`\zihao{-2}` 加粗居中 |
| 字体 | `fontset=windows` + `\setCJKmainfont{SimSun}[AutoFakeBold=3]`（原件用方正小标宋，本机没有，宋体加粗替代） |
| 固定内容 | 柔性电子学院 FE012402 / 学生 韩金宏 / 父亲 韩宗浩 / 电话 19991449005 |

要改姓名、学院、电话，改 `assets/template.tex` 正文那一段——**不要**在脚本里硬改。

## 编译与出图

- 引擎：优先本机 `xelatex`（TeX Live 2026 在 PATH），缺失时回退 `D:\tectonic-0.17.0-x86_64-pc-windows-msvc\tectonic.exe`
- JPG：PyMuPDF 直出 300 DPI；没有 PyMuPDF 就 `pdftoppm -png` + Pillow 转
- 正常结果：PDF 1 页；JPG 约 2481×3508（A4@300dpi）

## 交付时回报这几项

用一张小表 + 文件链接：

| 项 | 值 |
| --- | --- |
| 离开 / 返校 | 2026.10.27 / 2026.10.29 |
| 前往地点 | 上海 |
| 落款 | 2026年10月26日 |
| 产出 | PDF、JPG（300dpi）、TEX |

再说明：复制到 `I:\学习资料\0-个人资料\2-请假` 成功与否。若失败（PDF 被阅读器占用很常见），把失败原因写清楚并给出替代（关掉文件重跑 / 手动拷）。

## 坑位

- **右下角会有页码「1」**：原件就这样，保持一致；用户明确说不要页码时，在 `\begin{document}` 前加 `\pagestyle{empty}` 重编。
- **复制到 I 盘报 PermissionError**：目标 PDF 正被打开，关掉再跑。
- **编译输出中文乱码**：`subprocess` 必须 `encoding="utf-8", errors="replace"`，否则 GBK 解码会炸（历史踩过）。
- **地点含 `& % _ #`**：脚本已做 LaTeX 转义，别绕过脚本直接改 tex。
