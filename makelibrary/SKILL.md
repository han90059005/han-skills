# makelibrary

把一批文献 md 读一遍、打上标签，生成集中索引；之后 makepaper 先按标签筛选文件、只读相关文件。

## 何时用

- 有一批文献 md，想按主题/方向打标签、方便检索。
- 写论文前先建立「标签 → 文件」索引。

## 工作流程

1. **确认标签**：先问用户这批要打哪些标签（主题/方向，每次不同），据此生成 `tags.json`（标签 → 同义词/关键词）。
2. **跑脚本**（读一遍原文）：

```powershell
py <skill>/scripts/makelibrary.py --dir "文献目录" --tags "tags.json"
```

3. **产出**（在文献目录下）：
   - `_index.json`：机器可读，路径 → 标签 + 元数据 + 有效性 + 签名；
   - `_index.md`：可读清单，按标签分组并统计每类篇数。

4. **交给内容层**：makepaper 读 `_index.json`，按标签取文件路径，只读命中的文件。

## 标签词表格式

`tags.json`：

```json
{
  "电子皮肤": ["电子皮肤", "e-skin", "electronic skin", "tactile sensor"],
  "力学响应": ["力学响应", "mechano", "mechanical response"]
}
```

## 有效性标记

- 全文：含 `## 全文` 或正文较长；
- 摘要：含 `## 摘要` 或正文较短；
- 疑似无效：无标题或内容过短。

## 增量

重复运行时，签名（路径+修改时间+大小）未变、且标签词表未变的文件直接复用旧标签，只重扫新增/改动文件；换了标签词表则全部重新打标。
