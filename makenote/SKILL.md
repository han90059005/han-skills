# makenote（笔记 / 实验报告维护助手）

全部工作围绕一份 Markdown 文档开展，分两种模式：

- 模式一 学习笔记（默认）：围绕一份「当前目录名.md」随对话增量维护，见「核心规则」到「执行流程」。复习期可启用其子功能「可出题性筛查」。
- 模式二 实验报告：读 Excel 数据驱动更新报告、检测矛盾，交互补写分析，见「模式二：实验报告」。

## 与其他技能的区别

- 本技能：围绕一份固定笔记 md，随对话增量维护（新增/修改/订正）；复习期可直接在笔记上标注哪些内容值得投入、哪些可以跳过。
- course-review-generator：从课件 PPT 批量生成复习笔记，或合并多份已有笔记。
- makepaper：依据文献 md 合成带引用的论文/综述。
- makelatex / makedocx：只做最终排版（PDF / Word），不生成内容。

## 输入接口（归一化）

用户发来的 md/文本来源多样（paper-finder 文献、Zotero 全文、pptx 提取、pdf-reader 文本、course-review-generator 笔记、手打内容）。写入笔记前先归一化：

1. **定来源**：判断属于 课本摘录 / 课件 / 文献 / 其他，并打标签（[课本-Pxx]、[课件-Pxx]、[文献]、[个人推导]）。
2. **转干净 md**：课件等原始导出先转 pandoc 友好的干净格式，剔除多余标记、乱码、水印；统一标题层级与空行。
3. **去重对齐**：与笔记已有内容对比，重复的更新而不重复追加；同一主题合并到同一小节。
4. **存疑标注**：来源不明或内容可疑的标 [存疑待查]，不臆测。

归一化后再写入正式笔记区；中部构建逻辑不变，笔记仍以 Markdown 保存。

## 核心规则

**笔记文件名 = 当前工作目录的文件夹名 + `.md`**（目录名开头若带日期/时间前缀，如「时间·」「2026-09-08·」，该前缀省略，只保留核心内容）

例：若当前目录为「时间·固体物理讲义」，则笔记文件名为 `固体物理讲义.md`。

## 核心约束

1. 用户不会直接手动编辑这份笔记 md 文件。所有笔记的新增、修改、订正、补充，全部由用户在对话窗口发送文字/文件下达指令，由 AI 写入该 md。
2. 参考文件分为三类：
   - **课本**（多为 PDF）：通常文件很大。无用户明确指令时严禁完整读取全文，仅按需记录引用页码、关键结论。
   - **课件**：课件数据不能直接使用；必须先整理转换为 pandoc 友好、干净可二次编辑的格式，清洗乱码冗余，再提取有效内容并入笔记。
   - **其他文件**：根据文件用途灵活处理，具体情况具体分析。
3. 笔记 md 文件分为固定两大区块，顺序不可更改：
   ① 最顶部【记忆快照区】
   ② 快照下方【正式笔记区】

## 记忆快照区

用途：自包含全部工作记忆，只要把这份 md 丢进全新对话，再次调用 /makenote 就可以无缝继续工作，不需要用户重复交代背景。

快照模板（严格保留标记，每次操作结束自动更新）：

```markdown
# ⚙️ 记忆快照【请勿手动编辑，由AI自动维护】

> 快照由AI自动更新，用户不手动修改

- 当前工作模式：[新建笔记 / 接续笔记]
- 课程主题：
- 参考文件台账
  - 课本PDF：（记录文件名，非必要不全文解析）
  - 课件文件：（记录文件名，课件需先转为pandoc可编辑格式再摘录）
  - 其他资料：
- 考点筛查：[未做 / 已做 YYYY-MM-DD]
- 判据与偏好：（老师的出题习惯、明确不考的章节、已确认的题型分布、往年题来源）
- 用户固定偏好
  1. 用户不直接编辑笔记md文件，全部修改通过对话指令完成
  2. 课本PDF默认不全量读取，仅用户指定章节/页码才精读
  3. 课件先处理为pandoc可用干净格式，再整理进笔记
  4. 可出题性筛查只标注、不删除笔记内容
- 待办任务清单：
- 本次操作摘要：一句话简述本次执行动作
```

## 正式笔记区

使用标准 Markdown 排版；笔记内可区分标签：
- [课件-Pxx]
- [课本-Pxx，仅结论]
- [个人推导]
- [存疑待查]
- [拓展笔记]
- 考法标签（做可出题性筛查时才加，见该节）：[考:必练-计算] [考:易考-选择] [考:易考-简答] [考:扫一眼] [考:略]

## 可出题性筛查（模式一子功能）

用途：复习前先砍掉「不好出成题」的内容，把时间留给能变成题的知识点。**这是判断题，不是整理**：不增删正文，只在已有知识点上加考法标签，并在笔记末尾给一份汇总清单。

触发：「筛一下重点」「哪些不用管」「可考性」「哪些考不到」「帮我标考法」；或 /makenote 之后直接说「先筛一遍再讲」。

### 判据

依据优先级（高 → 低），用哪一档必须在清单里写明：

1. **往年题 / 真题 / 老师给的样卷** —— 有就按实际考过的题型定档；
2. **老师明确说过的范围或强调**（含课上点名、复习课划范围）；
3. **课件里的重复、例题、图、展开篇幅**；
4. **学科结构本身**（能否量化、有无判据）—— 前三者都没有时才用，且必须标「结构推断」。

**容易出题（值得投入）**

- 可代入数字、可推导的量与关系（公式、判据、等价条件）
- 有明确对错的辨析：适用边界、成立条件、反例
- 定理/公式被违反后会怎样（选择题常客）
- 量纲、数量级、极限情形与特例
- 能画成图的核心机制（相图、曲线、结构—性能关系）
- 分类之间有互斥判据的清单（可出简答）

**不好出题（可放过 / 只扫一眼）**

- 纯背景、发展史、人名年份
- 仪器操作步骤、样品制备细节、设备型号与工程参数
- 依赖某张特定插图才讲得清的机构描述
- 需要外部数据或特定实验条件才能算的算例
- 超长推导的中间步骤（保留起点假设与最终结论）
- 无法用一句话检验的罗列性清单

### 输出

1. 正文每个知识点末尾追加考法标签，三档 + 题型：
   `[考:必练-计算]`、`[考:易考-选择]`、`[考:易考-简答]`、`[考:扫一眼]`、`[考:略]`
2. 笔记末尾追加一节「## 考点筛查清单」，按三档分组，每条一句判据依据并注明依据来源档位。
3. **只标注，不删除**。判「略」的内容原样留在笔记里 —— 判错一次也不至于翻车。

### 硬约束

- 没有往年题时，禁止把结论写成「必考」，只能写「按结构易出 XX 题」。
- 写不出判据依据的条目不要标档，留空并说明还缺什么信息（例如缺真题、缺老师划范围）。
- 用户的判据偏好（本院系老师出题习惯、哪些章节不考、题型分布）写进快照的「判据与偏好」，后续沿用，不每次重问。
- 筛查只是建议，不代替用户的判断；用户推翻某条时，记入快照偏好，下轮不再反向标。

## 执行流程

当收到口令 /makenote：

**Step 1** 先获取当前工作目录名称，以此确定目标笔记文件名 `{目录名}.md`，然后检测当前工作目录或对话中是否已存在/提供该笔记文件。

- 情况 A：不存在该笔记文件 → 新建模式
  回复：「未检测到笔记记忆文件，将新建 `{目录名}.md`，请告诉我课程主题、提供参考文件，或直接发送笔记内容。」
  用户给出信息后，生成完整 md 文件，填充快照区，再录入笔记正文。
- 情况 B：已上传对应笔记文件 → 接续模式
  首先完整读取顶部【记忆快照区】，完整继承全部历史设定、进度、偏好，不得重置上下文。
  回复：「已加载笔记快照，接续当前笔记工作，请发送需要录入、修改、补充的内容或文件。」

**Step 2** 处理用户发来的内容/附件：

1. PDF 课本：没有用户明确要求，禁止全文解析，仅记录引用信息。
2. 课件文件：先整理为 pandoc 可编辑的干净格式，剔除多余标记、乱码，再提取有效内容写入笔记。
3. 其它文档：酌情处理。
4. 用户直接发文字笔记、推导、批注：结构化整理并入笔记正文。

**Step 3** 每一轮笔记更新完成：

1. 更新顶部记忆快照的全部字段，刷新台账、待办、操作摘要。
2. 输出完整更新后的笔记文件内容，文件名严格为 `{当前目录名}.md`。
3. 提示用户可以继续补充或提出修改要求。

**Step 4**（按需）用户要求筛考法时，走「可出题性筛查」：

1. 只读笔记已有标题与结论句即可判断，不需要补全残缺笔记。
2. 先问清三件事：有没有往年题、老师划没划范围、这门课偏计算还是偏简答；用户答不上就按「结构推断」降级。
3. 加考法标签 + 末尾「考点筛查清单」，同步更新快照的「考点筛查」「判据与偏好」。
4. 输出一页三档汇总：直接跳过 / 扫一眼 / 必投入，附判据依据，等用户确认或推翻。

## 模式二：实验报告（数据驱动）

用于「更新实验报告 / 加数据 / 添加实验」。哲学：数据与文字分离——数据来自 Excel（机器读），分析来自人工（交互写），脚本负责精确对齐与矛盾发现。

1. **确认项目目录**：目录下应有 `.xlsx` 数据源和（可选）`report_config.yaml`；配置模板见 `scripts/report_config_template.yaml`。
2. **跑脚本重建数据**：

```powershell
python scripts/update_report.py --base-dir "项目目录"
```

脚本读 Excel（按 Entry 组织）→ 对比旧报告 → 报出新增/变更/矛盾 → 生成新报告（按日期命名）并归档旧版。

3. **交互补写分析**：脚本生成的「结果与分析」「综合结论」文字由 AI 补写/订正；下次更新时保留人工文案、只重算数据表。
4. **依赖**：pandas + openpyxl + pyyaml。

## 禁止项

1. 要求用户手动修改 md 文件。
2. 在未被允许时完整读取大容量课本 PDF。
3. 课件未经格式整理，直接粘贴原始脏数据进笔记。
4. 丢失上下文信息，快照记录必须足够完备，保证跨会话可无损恢复。
5. 强行固定文件名为 course_notes.md，文件名必须跟随当前目录名自动生成。
6. 因为判了「略」就删除笔记内容，或反过来把所有内容都标成必练（筛查失去意义）。
7. 无往年题、无老师范围时把「结构推断」包装成「必考」。
