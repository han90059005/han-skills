# makepaper

把一组 Markdown 资料读入后，按用户每次给出的要求合成一篇高质量中文论文：正文用 `[n]` 角标交叉引用，文末附「参考文献」表。输出为 Markdown，可直接交给 makelatex 编译成 PDF。

## 与其他技能的区别

本技能只负责「依据文献 md 合成论文/综述正文 + 参考文献」；复习笔记生成/合并用 course-review-generator，交互式笔记维护用 makenote，最终排版转 PDF 用 makelatex、转 Word 用 makedocx。

## 输入接口（归一化）

源 md 可能来自 paper-finder、Zotero 插件、pdf-reader、course-review-generator 等，格式不统一。合成前先把每份源 md 归一化成一条「文献记录」，再做中部构建。

对每份源 md：

1. **定标题**：取首个 `# 标题`；无标题则用文件名兜底。
2. **提元数据**：从 `**作者**：`、`- 作者：`、`作者：`、`年份：`、`期刊：`、`DOI:`、`**DOI**：` 等写法中提取作者/年份/期刊/DOI。
3. **判深度**（优先级从高到低）：
   - 有 `## 全文` / `## 全文（自动提取）` 或很长的正文 → 全文级；
   - 有 `## 摘要` / `### 摘要` / `- 摘要：` / `Abstract` → 摘要级；
   - 只有标题与元数据 → 仅元数据，只登记来源。
4. **清洗**：剔除水印行、乱码、多余空行；统一用空行分段。
5. **编号**：给每条记录稳定编号 `[n]`，全文保持一致，供正文引用。

归一化完成后进入中部构建；中部构建逻辑不变，向后仍输出 Markdown。

## 每次必须确认的三项（缺一先向用户补齐，不要硬猜）

1. **md 文件夹地址**：要阅读的源 `.md` 所在目录
2. **生成地址**：论文 Markdown 写到哪个目录、文件名
3. **具体要求**：内容主题、结构、字数等

## 工作流

1. 列出并逐个读完源文件夹内所有 `.md`（忽略非 md 文件），源 md 只读、不修改。
2. 逐个判断内容类型，决定能引用到什么深度：
   - 有 `## 全文`（或很长的正文）→ 全文可用，可深入引用；
   - 只有 `## 摘要` → 只有摘要，只能引摘要级信息；
   - 只有元数据（标题 / 作者 / 年份 / 期刊 / DOI）→ 仅登记为来源，正文尽量少直接依赖。
3. 给每篇源 md 分配一个稳定编号 `[n]`，建立「源文件 → 编号」的一一映射（编号顺序自定并全文保持一致）。
4. 按用户要求撰写正文：
   - 严格满足内容主题、结构和字数要求；
   - 引用某篇来源时，在该句末写 `[n]`（多个用 `[1,2]`，连续用 `[1-3]`）；
   - 内容必须来自源 md，不臆造数据、结论或文献；源 md 没有的信息要克制，必要时明确说明「未覆盖」。
5. 文末写 `## 参考文献`，每条以 `[n]` 开头，信息取自对应源 md（作者、标题、期刊、年份、DOI）。
6. 写到用户指定的生成地址（文件名默认用题目 slug，或按用户指定）。

## 输出格式（与 makelatex 兼容）

- 第一个 `# 标题` 作为论文标题；
- 如需署名，标题后放「姓名 / 学号 / 作者」「日期」行；
- 正文空行分段，`[n]` 直接写在正文里；
- 最后 `## 参考文献` + 以 `[n]` 开头的条目。

若用户要求「转成 PDF」，再调用 makelatex 技能把这份 Markdown 编译为 PDF。
