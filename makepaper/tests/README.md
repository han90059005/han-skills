# makepaper 行为测试

6 个固定用例，检验 `makepaper/SKILL.md` 中的证据分级、来源独立性、因果措辞与修改规则。

> 所有用例均为虚构数据，只用于测试，不得当作真实文献或写入真实论文。

## 运行方式

没有自动化测试框架：让一个 Agent 读取 `../SKILL.md`，按 `tasks.md` 逐例执行，把输出写到临时目录，
再对照 `expected.md` 的检查点逐条判定。规则改动后重跑同一组用例即可回归。

## 目录

- `tasks.md`：6 个写作/修改任务
- `expected.md`：每个用例的预期行为（不是逐字范文）
- `RESULTS-2026-10-28.md`：本次测试结果、发现与复测限制
- `cases/`：源 md 与待修改草稿

## 通过标准

- 6 个用例全部满足 `expected.md` 的硬性检查点；
- 输出仍保持 `[n]` 引用格式与 Markdown 结构；
- 不为通过检查而伪造数据、DOI 或全文细节。
