# 规则测试记录（2026-10-28）

## 设置

- 同一套 6 个用例；盲测 Agent 只读 `SKILL.md` 与 `tasks.md`，不读 `expected.md`。
- 子 Agent 运行在只读沙箱，无法写输出文件；它的结论来自对话回复，完整段落由作者按同一规则自查生成。
- 判定依据 `expected.md` 的检查点，不要求逐字一致。

## 发现与修复

1. **数值误抄**：盲测暴露了“材料名对、数字错”的风险。已在 `SKILL.md` 的「主张与引用可追溯」新增规则：
   数值、单位、温度、时间、比例必须能在源 md 中逐字找到，相近材料逐项对表，不凭记忆改写或换算。
2. **用例 4 的功率因子物理不自洽**：原写 1800 μW m⁻¹ K⁻²，但 800×(150 μV)² 与 200×(300 μV)² 均约 18；
   已改为 18，避免测试变成算术陷阱。
3. **复测结果**：修正 fixture 与新增规则后，独立盲测复测用例 4 通过；复测 Agent 同样受只读沙箱限制，但只要求返回文本，因此本轮结论是独立生成、作者核对的。

## 局限

- 这是规则层行为测试，不是端到端编译测试；`makelatex` 的引用一致性未改动。
- 只能获取摘要时，无法核实全文的实验细节、统计与对照；规则只能保证“不越级表述”，不能消除信息缺失。
