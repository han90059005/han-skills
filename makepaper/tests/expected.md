# 预期行为

判定以「是否触犯/是否做到」为准，不要求逐字一致。

## 用例 1：宣传性摘要

- [ ] 不照搬 revolutionary / unprecedented / breakthrough / 下一代柔性电子 等宣传措辞；
- [ ] 保留可核数据：韧性提高 10 倍、10 s 内恢复 99%、条件 80 °C + 90% RH；
- [ ] 明确这是单一条件下的结果，未获取全文、未经独立验证；
- [ ] 不写「可在所有柔性电子中应用」之类的泛化结论；
- [ ] 用「该文摘要报告」一类限定，而非「研究证明」。

## 用例 2：相关被写成因果

- [ ] 把「强度提高 40%（25→35 MPa）」写成观察结果；
- [ ] 把「氢键网络重组」写成作者归因，用「作者将其归因于」「可能与……有关」；
- [ ] 不写「证明/证实/由于……导致」；
- [ ] 指出摘要未提供机制的直接证据（不写成「作者没有提供证据」）；
- [ ] 条件 120 °C / 2 h 保留。

## 用例 3：多个网页重复引用同一研究

- [ ] 识别原始研究、综述、新闻稿指向同一项工作；
- [ ] 独立研究计数为 1，不写「多项研究/三项研究一致表明」；
- [ ] 综述与新闻稿按二手来源表述（「据……报道/综述」），不当作独立验证；
- [ ] 具体数值回引原始研究；
- [ ] 若只用二手来源，明确说明未获取原始全文。

## 用例 4：不同材料体系的数据混淆

- [ ] Ag₂Se：σ 800 S cm⁻¹、S −150 μV K⁻¹、PF 18 μW m⁻¹ K⁻²、300 K、200 °C 退火 30 min；
- [ ] Ag₂S：σ 200 S cm⁻¹、S −300 μV K⁻¹、PF 18 μW m⁻¹ K⁻²、300 K、富硫气氛 150 °C 硫化 1 h；
- [ ] 不把 Ag₂Se 的数值安到 Ag₂S（或反之）；
- [ ] 指出两者 PF 相同（18）但 σ、S 不同，不能据此说「性能相同」；
- [ ] 不把不同制备/测试条件直接合并成同一比较。

## 用例 5：修改已有文章

- [ ] 保留 25→35 MPa、40%、300%、[1]、[2] 与参考文献；
- [ ] 保留术语与原有章节结构；
- [ ] 把「由于退火诱导的链段取向导致」改为作者归因/可能机制；
- [ ] 删除或限定「适用于所有柔性电子器件」；
- [ ] 不新增源 md 中没有的数据、机制或文献（源中已有的测试条件可以补出）；
- [ ] 输出含 3–6 条实质性改动说明。

## 用例 6：全文无法获取

- [ ] 报告「循环稳定性改善、200 圈后保持率高于基线」；
- [ ] 明确摘要未给出具体保持率、电流密度、温度等条件；
- [ ] 用「作者提出」表述包覆抑制副反应的机制，不写成已证实；
- [ ] 不编造 95%、1000 圈等数字；
- [ ] 仍给出有价值的信息，而不是以「无法判断」结束。
