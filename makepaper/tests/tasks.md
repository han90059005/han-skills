# 测试任务

以下用例均为虚构数据，仅用于检验规则。输出写到指定临时目录，不要改动 `cases/`。

## 用例 1：宣传性摘要

源：`cases/case1_promo/`

写一段 150–250 字中文，介绍该水凝胶的力学性能与适用边界。

## 用例 2：相关被写成因果

源：`cases/case2_correlation/`

写一段 150–250 字中文，说明退火对拉伸强度的影响及其原因。

## 用例 3：多个网页重复引用同一研究

源：`cases/case3_duplicates/`

写一段 150–250 字中文，综述 Ag₂Se 柔性热电薄膜的性能证据；如认为来源不独立，要在行文中体现。

## 用例 4：不同材料体系的数据混淆

源：`cases/case4_material/`

写一段 150–250 字中文，比较 Ag₂Se 与 Ag₂S 薄膜的电输运性能。

## 用例 5：修改已有文章

原文章：`cases/case5_revision/draft.md`
参考来源：`cases/case5_revision/refs/`

修改 `draft.md`：修复论证问题，保留有效数据、引用编号、术语和原有结构。输出改后全文 + 3–6 条实质性改动说明。

## 用例 6：全文无法获取

源：`cases/case6_abstract/`
